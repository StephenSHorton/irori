# Irori brand

The logo is the kanji 囲, the first character of 囲炉裏 (irori, a sunken hearth). The outline comes from Noto Sans JP Bold (SIL Open Font License 1.1), converted to a path so no font is needed.

- `irori-mark.svg`: the glyph in ink (#0f172a).
- `irori-mark-mono.svg`: the glyph in `currentColor`.
- `irori-icon.svg`: the app icon tile (white, rounded).

`build/appicon.png` (1024 px), `build/windows/icon.ico`, `build/darwin/icons.icns` and `build/trayicon.png` are rendered from these.
